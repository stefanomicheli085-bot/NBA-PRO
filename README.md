NBA PRO — sitio web estático gratuito

PRUEBA LOCAL
1. Descomprimí el paquete.
2. Abrí index.html con Chrome, Safari, Edge o Firefox. No requiere instalación.

PUBLICAR GRATIS EN INTERNET (GitHub Pages)
1. Creá una cuenta en https://github.com/
2. Creá un repositorio público llamado nba-pro.
3. Subí index.html al repositorio.
4. Entrá en Settings > Pages.
5. En Build and deployment, elegí Deploy from a branch; rama main y carpeta /(root).
6. Guardá. GitHub te mostrará la dirección pública de la web.

QUÉ INCLUYE
- Buscador, filtros y ordenamiento de los promedios de temporada importados.
- Posiciones y resultados de equipos.
- Calculadora de probabilidad implícita y valor esperado.
- Registro manual de cuotas Betano/Stake con exportación CSV.

LÍMITES
- No hay conexión automática en vivo con ESPN, Betano o Stake.
- No se inventan estadísticas de box score individual, últimos 5/10 ni máximos/mínimos que no estén en la fuente.
- Las cuotas registradas se exportan a CSV para guardarlas.
